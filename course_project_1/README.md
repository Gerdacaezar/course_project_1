# Приложение для анализа транзакций


## Описание

Приложение предназначено для анализа финансовых транзакций, хранящихся в Excel‑файлах. Оно предоставляет:
- генерацию JSON‑данных для веб‑интерфейса;
- формирование структурированных Excel‑отчётов;
- дополнительные сервисные функции для работы с финансовыми данными.

## Функциональные возможности

- **Импорт данных**: чтение транзакций из Excel‑файлов (`*.xlsx`).
- **Фильтрация и обработка**: выборка операций по дате, категории, сумме.
- **Анализ трат**: подсчёт сумм по категориям, периодам, картам.
- **Генерация отчётов**:
  - JSON для веб‑страниц (API‑ответы);
  - Excel‑файлы с детализацией операций.
- **Сервисы**:
  - расчёт кэшбека по категориям;
  - сводка по картам;
  - топ‑транзакции за период.

## Запуск

1. Поместите входной Excel‑файл в `data/operations.xlsx` (или укажите путь в коде).
2. Запустите приложение:
   ```bash
   python main.py
   ```
3. Результаты будут выведены в консоль и сохранены в:
   - `output/report_*.json` (JSON‑отчёты);
   - `output/report_*.xlsx` (Excel‑отчёты).

## Конфигурация

- **Путь к входному файлу**: измените в `main.py` или передайте как аргумент.
- **Формат дат**: ожидается `дд.мм.ГГГГ ЧЧ:ММ:СС` в Excel и `ГГГГ‑ММ‑ДД ЧЧ:ММ:СС` в параметрах.
- **Логирование**: настройки в `config/logging_config.py` (уровень, формат, вывод).


## API‑эндпоинты (пример)


- `GET /home` — главная страница (JSON с приветствием, картами, топ‑транзакциями).
- `GET /cashback?year=2025&month=1` — расчёт кэшбека по категориям.
- `GET /spending?category=Супермаркеты&date=2025-01-15` — анализ трат по категории.


## Формат входных данных


Файл `data/operations.xlsx` должен содержать лист с колонками:
- `Дата операции` (формат: `дд.мм.ГГГГ ЧЧ:ММ:СС`);
- `Категория` (строка);
- `Сумма операции` (число, отрицательные значения — расходы);
- `Карта` (опционально).

## Логирование

- Все действия записываются в консоль и файл `app.log`.
- Уровни: `INFO` для событий, `ERROR` для исключений.
- Настройка в `config/logging_config.py`.

## Обработка ошибок

- Невалидный Excel‑файл → лог ошибки, возврат пустого результата.
- Отсутствие колонки в Excel → исключение с описанием.
- Некорректный формат даты → лог, пропуск записи.
